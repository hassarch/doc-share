## 🎨 Design System Overview

### Color Palette
- **Neutral**: 50-900 (grays)
- **Primary**: 50-700 (blue/teal)
- **Success**: 50-700 (green)
- **Warning**: 50-700 (yellow/orange)
- **Error**: 50-700 (red)
- **Info**: 50-700 (light blue)

### Typography
- **Font Sizes**: xs (12px) to 4xl (36px)
- **Font Weights**: normal (400) to bold (700)
- **Line Heights**: Optimized for readability
- **Font Family**: System fonts with fallbacks

### Spacing Scale
- **4px increments**: 1, 2, 3, 4, 6, 8, 12, 16, 24, 32
- **Consistent gaps**: Applied throughout
- **Responsive**: Adapts to screen size

### Elevation System
- **6 levels**: xs, sm, md, lg, xl, 2xl
- **Consistent shadows**: Applied by hierarchy
- **Depth perception**: Clear visual layers

### Animation System
- **Duration**: 200ms (interactions), 300ms (layouts)
- **Easing**: ease-out, ease-in-out
- **GPU-accelerated**: Transform-based
- **Smooth**: No jank or flicker
